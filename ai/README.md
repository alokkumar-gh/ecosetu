# EcoSetu AI Microservice

FastAPI microservice for e-waste image classification using YOLOv8.

## Structural Foundation
- `src/main.py`: Application entry point and health-check endpoint.
- `requirements.txt`: Python package specifications.
- `Dockerfile`: Container configuration for production deployment.

Full model training and inference pipelines will be implemented in subsequent phases according to `docs/11_AI_EWASTE_DETECTION.md` and `docs/12_AI_TRAINING_PLAN.md`.
